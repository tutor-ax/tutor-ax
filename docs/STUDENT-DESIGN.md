# 학생용 학습 노트 개편

## 범위

학생 로그인·성적 조회·단어·지문 학습을 개편했다. 이전 HTML의 데이터/업무 결과 비교는 유지하되 학생 화면의 크기·배치 일치 요구는 사용자 요청에 따라 해제했다. 관리자 내부 컴포넌트와 CSS는 변경하지 않았다. 관리자 라우트가 학생 레이아웃 내부에 렌더링되는 문제는 별도 조기 반환으로 수정했다.

## 디자인과 UX

- 짙은 녹색 잉크, 밝은 종이색, 구분선과 여백을 중심으로 한 학습 노트. 과한 그림자와 카드 중첩을 줄였다.
- 학생 전용 `.student-shell` 아래에 스타일을 한정해 관리자와 분리했다.
- 성적 화면은 선택 주차의 결과, 클리닉, 추이와 주차 기록을 나란히 배치하고 모바일에서는 한 열로 읽는다.
- 시험 항목/만점/결석 조건이 다른 결과는 단순 증감 비교를 보류한다. 기존 누적 평균/차트는 기존 계산을 유지하므로 결석 0점도 포함되는 기존 정책을 따른다.
- 단어 화면에 선택 범위 요약, 검색과 학습 단계 안내를 추가했다. 지문은 문장별 읽기와 해석을 강조했다.
- 키보드 초점·본문 건너뛰기·감소된 동작 설정·모바일 버튼 크기를 고려했다.
- 제목용 Gowun 폰트 서브셋은 자체 호스팅한다. 라이선스: `src/assets/fonts/OFL.txt`.

## 도구

Impeccable 4.7.0을 프로젝트 범위에 설치해 사용했다. 재설치:

```sh
npx impeccable@4.7.0 install --providers=claude --scope=project --no-hooks --yes
```

설치된 도구/바이너리와 로컬 디자인 작업 상태는 Git에서 제외한다. 제품 맥락은 `PRODUCT.md`, 실제 학생 스타일은 `src/styles/student.css`에 남긴다.

## 실행 검증

- `npm test -- --run`: 15개 파일, 48개 테스트 통과.
- `npm run build`: TypeScript 및 Vite 빌드 통과.
- `npm run test:e2e`: 14개 통과. 기존 데이터 비교·학습 흐름·관리자 동작·CSP 확인 포함.
- `npm run test:pages`: 7개 통과. 관리자 별칭과 새로고침, 학생 화면과 중첩되지 않음, 관리자에서 나가기 검증 포함.
- 390px·1440px에서 로그인/성적/단어/플래시카드/지문/관리자 스크린샷 생성. 로컬 증거: `/tmp/tutor-redesign-evidence/after/`.
- 직접 확인한 화면: 모바일 성적·지문, 데스크톱 성적·관리자. 관리자 화면은 학생 헤더/탭 없이 독립적으로 표시된다.

재촬영: 일반 `npm run build` 후 4175 포트로 preview 실행하고 `node scripts/capture-design.mjs after` 실행.

실제 학생 대상 사용성 조사를 완료했다는 의미는 아니다. 운영 DB·인증·AI·알림톡은 이번 변경에 연결하지 않았다.
