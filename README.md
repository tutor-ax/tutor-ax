# tutor-ax

기존 학원 HTML 서비스의 디자인과 업무 규칙을 유지하는 React 마이그레이션 작업본입니다.

> **현재는 합성 데이터 전용 개발본입니다. 운영 로그인·DB·SMS와 연결되어 있지 않습니다.**
> 고객 저장소와 운영 사이트는 변경하지 않습니다. 이 저장소는 Private으로 유지합니다.

## 현재 범위

| 영역 | 상태 |
| --- | --- |
| React + TypeScript + Vite 공통 기반 | 구현 |
| 성적 확인 화면 | 데모 데이터로 구현·테스트 |
| 주간/모의고사 선택, 동적 채점 항목, 재시험, 결석, 과제, 클리닉 메모 | 구현 |
| 평균·석차·누적 평균·최고 점수·Chart.js 추이 | 구현 |
| 데모 세션 유지·로그아웃·브라우저 뒤로 가기 | 구현 (실제 인증 아님) |
| 운영 로그인·서버 세션·실제 데이터 조회 | 미연결 — 별도 테스트 백엔드 확인 필요 |
| 관리자 / 단어 공부 / 지문 공부 | 다음 단계. 경로만 유지한 안내 화면 |
| OCR·RAG·클리닉 에이전트 | 아직 구현하지 않음 |

## 실행

Node.js 22와 npm 10.9 이상을 권장합니다. 로컬 검증은 Node 20.12.2에서도 수행했습니다. `.nvmrc`는 프로젝트용 권장 버전이며 시스템 Node를 자동 변경하지 않습니다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173 에서 **데모로 둘러보기**를 누릅니다. 실제 학생 이름이나 PIN을 입력할 필요가 없습니다. 기존 로그인 폼은 디자인 보존용이며 운영 인증을 수행하지 않습니다.

빌드된 결과 확인:

```sh
npm run build
npm run preview
```

http://127.0.0.1:4173

브라우저 데이터 통신은 기본 차단합니다. 개발 서버에서만 로컬 Vite HMR WebSocket을 허용합니다. Google Fonts는 기존 디자인 유지를 위해 스타일·폰트 요청만 허용하며, 인터넷이 없으면 시스템 글꼴을 사용합니다.

## 검증

```sh
npm test -- --run
npm run build
npx playwright install chromium --no-shell
npm run test:e2e
npm audit
```

- 단위·React 통합 테스트: 계산, 데모 세션, 미입력/빈 데이터, 오류, HTML 텍스트 안전 표시, 미이관 경로.
- Playwright: 원본 HTML과 React에 같은 합성 데이터를 넣어 390px·1440px 화면의 표시 내용 및 주요 요소 크기 비교.
- 운영 API·외부 데이터 연결이 CSP로 차단되는지 실제 브라우저에서 확인.
- `test-results/`에 비교 스크린샷, `playwright-report/`에 실행 보고서 생성. `npx playwright show-report`로 확인.
- 테스트는 운영 사이트를 열거나 운영 DB에 요청하지 않습니다.

## 구성

```text
src/
  App.tsx             로그인 모양·데모 진입·탭·브라우저 이동
  Scores.tsx          주간/모의고사·점수 카드·차트 React 컴포넌트
  domain.ts           순수 성적 계산·설정·날짜 정렬
  gateway.ts          데이터 접근 계약과 데모 세션 구현
  data/demo-score.json 명시적 합성 데이터
  styles/             기존 공통/성적 CSS를 기반으로 한 스타일
tests/                단위·컴포넌트 회귀 테스트
e2e/
  fixtures/           원본/React 공통 합성 응답
  legacy/             운영 연결을 제거한 원본 비교 전용 HTML/CSS
  *.spec.ts           브라우저 동작·안전성·레이아웃 비교
docs/                 이전 범위·차이·출처·검증 기록
```

`e2e/legacy`는 테스트 비교용이며 배포 산출물에 포함되지 않습니다. React 앱은 레거시 HTML/스크립트 실행, iframe, `dangerouslySetInnerHTML`에 의존하지 않습니다.
